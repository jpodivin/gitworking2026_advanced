# Roadmap

The next major release is focused on making Fernpress easier to extend without
turning it into a full application framework.

## Planned themes

- Template inheritance for shared layout fragments.
- A small, explicit plugin hook surface for content transforms.
- Configurable asset fingerprinting.
- Better diagnostics for malformed content collections.
- A more complete Markdown conformance test suite.

Ideas may move between releases. Discussion belongs in an issue before a large
implementation is started.
